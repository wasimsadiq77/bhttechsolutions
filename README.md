# BHT Tech Solutions

WordPress block theme prepared for hosting on Hostinger.

- [Download the installable WordPress theme](https://github.com/wasimsadiq77/bhttechsolutions/raw/refs/heads/main/output/bht-tech-wordpress-theme.zip)
- [Installation guide](output/INSTALL-HOSTINGER.md)
- [Standalone HTML preview](output/preview.html) — download and open in your browser.
- [Editable theme source](wordpress/bht-tech)

Upload only `output/bht-tech-wordpress-theme.zip` through WordPress → Appearance → Themes → Add New → Upload Theme. The repository ZIP is not the installable theme.

Includes custom software, Zoho, Odoo, ERP and computer hardware services, published contact details and the BHT Trading connection.

Package structure, configuration, serialized block nesting and contact links were checked. Live WordPress and browser testing remain required before production. This repository does not deploy or replace the existing Hostinger site.
