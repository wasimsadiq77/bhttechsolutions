# BHT Tech Solutions — WordPress theme

## Files
- bht-tech-wordpress-theme.zip: installable WordPress block theme.
- preview.html: standalone browser preview. Open locally; no server required.

## Install on Hostinger
1. Back up the existing website, DNS settings and any email configuration. Keep the Website Builder site available until the WordPress version is checked.
2. Set up a separate WordPress installation in Hostinger, preferably on a staging domain or temporary URL. This theme requires WordPress 6.4+ and PHP 7.4+; use currently supported WordPress and PHP releases.
3. In WordPress, open Appearance → Themes → Add New → Upload Theme. Select bht-tech-wordpress-theme.zip, install and activate it. This is a theme ZIP, not an Elementor kit, WordPress XML content export or All-in-One WP Migration backup.
4. The front-page template supplies the homepage automatically. If an existing installation has a static homepage selected, the front-page template still applies. Set your site title to BHT Tech Solutions in Settings → General.
5. Open Appearance → Editor. Edit the Front Page template, Header and Footer. Most text, headings, buttons and sections are native blocks. The connected-business illustration is a Custom HTML block. Replace the typographic BHT mark with your approved logo if desired.
6. Review the five services and proposed project approach. The content does not assert certifications, client results, awards or service guarantees.
7. Confirm all contact details. The existing site's indexed contact information is info@bhttechsolution.com (singular), support@bhttechsolutions.com, +971 54 2653991, Al Hilal Bank Building, Al Nahda St, Dubai, UAE. The first email has deliberately not been changed to a different spelling.
8. Test the navigation, email, telephone, WhatsApp and map links on mobile and desktop. Email opens the visitor's email application; WhatsApp opens a chat. There is no server-side enquiry form or delivery promise.
9. Add an approved privacy notice if you add analytics or a form. Add your chosen SEO plugin to manage metadata and social previews. No paid plugins, fonts or remote image assets are required by the theme.
10. Once staging is approved, use Hostinger's supported process to connect the production domain to WordPress and enable HTTPS. Preserve existing MX and other email-related DNS records. Website Builder hosting and WordPress hosting are separate workflows; uploading this theme into Website Builder will not work.

## Editing
Change global colors and typography through Site Editor → Styles. Template edits stored by WordPress override theme files; use the Site Editor to inspect or reset a template if later theme-file changes do not appear. Back up before resetting customizations.
